# 🔌 Панель управления вентилятором для OpenWrt (LuCI)

**Удобный и красивый веб-интерфейс в темной теме для настройки охлаждения вашего роутера.** Панель интегрируется прямо в стандартное меню OpenWrt (LuCI) и позволяет переключать режимы работы вентилятора в один клик.

## ✨ Основные возможности панели

*   **Полная интеграция:** Добавляет пункт управления прямо в главное меню роутера.
*   **Стильный дизайн:** Современный интерфейс (`Fan General Control`) в темных тонах.
*   **Умная автоматика:** Режим `Авто (драйвер)` для самостоятельной регулировки скорости в зависимости от нагрева.
*   **Готовые пресеты:** Переключение вентилятора в ручные режимы `Тихо`, `Баланс` или `Турбо`.
*   **Тонкая настройка:** Возможность задать точное значение мощности (PWM) вручную.
*   **Информативность:** Вывод текущей температуры процессора и реальной скорости вентилятора на экран в реальном времени.

## 🚀 Пошаговая установка

Вам не нужно ничего скачивать на компьютер или клонировать репозиторий. Установка происходит автоматически прямо внутри роутера. Всё, что вам нужно — это доступ к консоли роутера.

### Шаг 1. Откройте терминал роутера
Вы можете сделать это любым удобным способом:
*   **Через браузер (самый простой):** Зайдите в меню роутера и проверьте, есть ли у вас вкладка **Система** ➡️ **Терминал** (LuCI TTyd Terminal). Если есть — откройте её.
*   **Через SSH:** Откройте терминал на вашем компьютере (или программу PuTTY / Termius) и подключитесь к вашему роутеру по SSH.

### Шаг 2. Запустите установку одной командой
Скопируйте команду ниже, вставьте её в терминал роутера и нажмите **Enter**:

```bash
wget --no-check-certificate -qO- https://githubusercontent.com | sh -s -- 127.0.0.1
```

**Что произойдет дальше:** Роутер сам скачает скрипт установки с вашего GitHub, автоматически распакует файлы интерфейса, распределит их по нужным системным папкам, настроит права доступа и перезапустит веб-службы. Это займет всего пару секунд.

## 💻 Как открыть панель в браузере

После того как скрипт завершит работу, просто обновите страницу с админкой вашего роутера. Панель можно найти двумя способами:

1. **Через меню:** Перейдите в верхнее меню веб-интерфейса и выберите раздел: **Службы** (Services) ➡️ **Управление вентилятором** (Fan Control).
2. **По прямой ссылке:** Вставьте в адресную строку браузера адрес в таком формате, подставив IP-адрес **вашего** роутера:
   ```text
   http://[IP_АДРЕС_ВАШЕГО_РОУТЕРА]/cgi-bin/luci/admin/services/fancontrol
   ```
   *(Например, если в настройки своего роутера вы заходите по адресу `192.168.31.1`, то ссылка для быстрого перехода в панель будет: `http://192.168.31`)*

## 🛠️ Доступные режимы работы

В веб-панели вам доступны следующие варианты управления:

*   **Авто (драйвер):** Оптимальный режим. Роутер сам решает, когда ускорить вентилятор, ориентируясь на встроенные датчики температуры.
*   **Тихо:** Вентилятор переходит на минимальные обороты. Идеально для ночи или если роутер стоит в спальне.
*   **Баланс:** Стандартный ручной режим для повседневной работы со средним уровнем охлаждения и шума.
*   **Турбо:** Максимальное охлаждение. Вентилятор включается на полную мощность (100%). Рекомендуется при высоких нагрузках или в жаркую погоду.
*   **Свой PWM (Ручной ввод):** Позволяет выставить точное числовое значение скорости, после чего нужно нажать кнопку **«Применить PWM»**.
